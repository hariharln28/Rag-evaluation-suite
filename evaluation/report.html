Interpretation

The retrieval component performed poorly: only 1 out of 31 queries retrieved the correct passage within the top‑5 results (3.23%). This indicates that the BM25 index, as currently built, is not distinguishing the relevant passages. Possible causes include:

  • All passages are extremely short and share many common tokens, limiting BM25 discriminative power.
  • Passage IDs are not being used as part of the document text, so the model cannot learn the association between a question and its numbered passage.
  • Only a single tokenization strategy (simple word split) is used; more sophisticated preprocessing (stop‑word removal, stemming, n‑grams) might help.

Generation accuracy is higher (32.26%) because many of the gold answers appear as substrings in the first retrieved passage (which is always passage 1 due to the current scoring). For questions that happen to match content in passage 1, the generation check passes, otherwise it fails.

To improve the system:

  1. Enrich the corpus: provide longer, more distinctive passages or add multiple variants per fact.
  2. Improve indexing: enable BM25 n‑gram weighting, remove stop words, or switch to a dense retriever (e.g., Sentence‑Transformers).
  3. Tie questions to passage IDs: include the ID in the text or store a separate mapping that can be used to boost the expected passage during retrieval.
  4. Add a fallback for unanswerable questions: currently the unanswerable case is not distinguished; a confidence threshold could be used to return "no answer".

With these changes, we would expect retrieval accuracy to rise, which in turn should boost overall generation performance.
