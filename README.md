# RAG Evaluation Suite

A lightweight evaluation framework for Retrieval‑Augmented Generation (RAG) systems.

## Overview
This repository provides:
- A small **corpus** of factual passages (`evaluation/corpus.txt`).
- A set of **questions** with gold answers (`evaluation/questions.json`).
- A **hybrid retrieval script** (`evaluation/eval.py`) that combines BM25 and a Sentence‑Transformers dense retriever.
- An **HTML report** (`evaluation/report.html`) summarising retrieval and generation scores.
- A **Vercel configuration** (`vercel.json`) to host the HTML report as a static site.

## Repository structure
```
.
├─ docs/                     # Miscellaneous documentation
│   └─ doc1.txt
├─ evaluation/               # Core evaluation assets
│   ├─ corpus.txt            # 10 factual passages (ID‑prefixed)
│   ├─ questions.json        # 31 question/answer pairs (incl. 1 unanswerable)
│   ├─ eval.py               # Hybrid BM25 + dense retrieval evaluation script
│   ├─ requirements.txt      # Python dependencies
│   ├─ report.html           # HTML report (title: "RAG Evaluation Suite")
│   └─ results.csv           # CSV output generated by eval.py
├─ vercel.json               # Vercel static‑site config (serves report.html at /)
└─ README.md                 # ← This file
```

## Getting started (local)
1. **Install Python 3.14+** (already available on the host machine).
2. Install dependencies:
   ```powershell
   cd evaluation
   pip install -r requirements.txt
   ```
3. Run the evaluation script:
   ```powershell
   python eval.py
   ```
   The script prints a markdown summary, writes `results.csv`, and updates `report.html` with the latest scores.
4. Open the report locally (no server needed):
   ```powershell
   start evaluation\report.html
   ```

## Deploying to Vercel
The repo contains a `vercel.json` that tells Vercel to serve all files under `evaluation/` as static assets and map the root URL (`/`) to the report.

### Using the Vercel dashboard
1. Log in to https://vercel.com.
2. Click **New Project → Import Git Repository** and select `hariharln28/Rag-evaluation-suite`.
3. Vercel will detect `vercel.json`; simply click **Deploy**.
4. After deployment, the live URL (e.g., `https://rag-evaluation-suite.vercel.app/`) will display the **RAG Evaluation Suite** page.

### Using the Vercel CLI (optional)
```powershell
npm i -g vercel   # install once
vercel login       # authenticate in browser
vercel --prod      # run from the repo root
```

## Customising the evaluation
- **Add more passages**: Append new, uniquely‑identified entries to `evaluation/corpus.txt` (format `ID\nText`).
- **Add questions**: Extend `evaluation/questions.json` with additional objects following the existing schema.
- **Adjust hybrid weighting**: Edit `alpha` in `eval.py` (0 = pure dense, 1 = pure BM25).
- **Rerun** the script to see updated scores.
